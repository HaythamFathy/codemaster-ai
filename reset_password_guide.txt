CHANGE PASSWORD TO SIMPLE ONE
=============================

The easiest fix is to change your database password to something without special characters (like `@`).

1. Go to Supabase
   Go to Project Settings -> Database -> Roles.
   Or: https://supabase.com/dashboard/project/_/settings/database

2. Change Password for 'postgres'
   - Click the three dots next to the `postgres` user.
   - Click "Reset Password".
   - Set it to something simple like: `HaythamPua012345` (Letters and Numbers ONLY).
   - Click "Reset".

3. Get New Connection String
   - Go to "Connect" button (top right).
   - Select "Transaction Pooler" (Port 6543) or Direct (Port 5432).
   - Copy the URI.
   - Replace `[YOUR-PASSWORD]` with the new simple password.

4. Valid URL Example
   `postgresql://postgres.ukdxxxxx:HaythamPua012345@aws-0-us-east-1.pooler.supabase.com:6543/postgres`

5. Update Vercel
   Update `DATABASE_URL` and Redeploy.
