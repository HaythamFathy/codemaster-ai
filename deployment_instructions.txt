DEPLOYMENT INSTRUCTIONS FOR VERCEL
==================================

I have simplified the setup. You now have a root `package.json` that handles the build automatically.

1. Push to GitHub
-----------------
Run these commands in your VS Code terminal to save the fixes:

   git add .
   git commit -m "Fix Vercel build and restructure"
   git push origin main

2. Import Project in Vercel
---------------------------
- Go to https://vercel.com/new
- Select your repository (`haythamfathy/codemaster-ai`).
- Leave **ALL** Build and Output settings at their **Default** values.
  - Framework Preset: Other (or Next.js, doesn't matter much with custom root package.json, but Next.js is fine)
  - Root Directory: `./` (Default)
  - Build Command: `npm run build` (Default)
  - Output Directory: `frontend/.next` (Important: The build script I made outputs here, but Vercel might expect `.next` in root. 
    *Correction*: With Next.js preset, it looks for `.next`.
    *Wait*, my root package.json builds into `frontend/.next`.
    *Action*: I should probably override the Output Directory in Vercel settings to `frontend/.next` OR move the .next folder.
    
    *Let's check Vercel behavior*: If Root is `./`, Vercel expects output in `./.next` for Next.js.
    *My script*: `cd frontend && npm run build`. This creates `frontend/.next`.
    *Solution*: Set "Output Directory" to `frontend/.next`.

    **REVISED INSTRUCTIONS FOR SETTINGS:**

    - Build Command: `npm run build`

3. Environment Variables
------------------------
Add these in the deployment screen:

   Key                          Value
   ---                          -----
   SECRET_KEY                   <random_string>
   ALGORITHM                    HS256
   ACCESS_TOKEN_EXPIRE_MINUTES  30
   ALLOWED_ORIGINS              https://your-project.vercel.app,http://localhost:3000

4. Deploy
---------
Click "Deploy".
