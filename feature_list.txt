CodeMaster AI - Feature Summary
===============================

1. Authentication & Users
-------------------------
- Secure Registration & Login: JWT-based authentication with bcrypt password hashing.
- Google Authentication: Seamless sign-in with Google OAuth.
- Role-Based Access Control: 
  - Students: Access courses and dashboard.
  - Admins: Dedicated Admin Panel for content management.
- Session Management: Secure cookies with Lax SameSite policy for robust auth flow.

2. Learning Environment
-----------------------
- Video Player: Embedded YouTube player for immersive lessons.
- In-Browser IDE: Monaco Editor (VS Code engine) for writing and editing code.
- Split-View Design: Learning content and coding environment side-by-side.
- AI Tutor:
  - Error Analysis: Intelligent feedback when code fails.
  - Success Feedback: Encouraging messages ("Supportive Senior Engineer" persona).
  - Powered by OpenAI API.

3. Code Execution System
------------------------
- Secure Execution: Code is run safely using a local Python process (or Docker if configured).
- Live Output: Real-time capture of stdout/stderr displayed in the UI.
- Automated Testing: Submissions are validated against predefined test cases.
- Pydantic V2 Compatibility: Modern data validation schema.

4. Dashboard & Navigation
-------------------------
- Student Dashboard: Overview of progress and available courses.
- Course Listings: Dynamic fetching of courses from the database.
- Profile Management: View user stats and streak (User Avatar).
- Responsive Navigation: Navbar updates state immediately upon login/logout.

5. Content Management (Admin)
-----------------------------
- Admin Panel: Protected route (`/admin`) for authorized users.
- Course Creation: UI to add new courses.
- Lesson Management: Add video lessons and challenges.

6. Tech Stack
-------------
- Frontend: Next.js 14, Tailwind CSS, TypeScript, Lucide Icons.
- Backend: FastAPI, SQLAlchemy, PostgreSQL/SQLite.
- Infrastructure: Vercel Deployment ready (Supabase/Postgres compatible).
