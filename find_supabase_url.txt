FINDING THE CORRECT SUPABASE URL
================================

The error "No such host is known" means the address we have is wrong (typo or invalid).

1. Go to Supabase Dashboard
   https://supabase.com/dashboard/project/_/settings/database

2. Look for "Connection String"
   - Look at the top right, click **"Connect"**.
   - Select **"URIs"**.
   - **CRITICAL:** Look for a tab or dropdown that says **"Transaction Pooler"** or "Mode: Transaction".
     (This usually runs on port **6543**).

3. Copy that URL
   It should look something like:
   `postgresql://postgres.projectref:password@aws-0-us-east-1.pooler.supabase.com:6543/postgres`
   
   *Note: It is much better for Vercel because it handles many connections!*

4. Paste it here
   Paste it in the chat (you can hide your password with `****` if you want), or update the `debug_db.py` file yourself.
